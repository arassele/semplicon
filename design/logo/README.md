# Logo Semplicon

| File | Uso |
|---|---|
| `semplicon_logo_fondo_scuro.svg` | Logo orizzontale (simbolo bianco e verde salvia, scritta bianca) per fondi scuri, ad es. barra laterale |
| `semplicon_logo_fondo_chiaro.svg` | Logo orizzontale (verde scuro e verde salvia) per fondi chiari |
| `semplicon_simbolo_fondo_scuro.svg` | Solo simbolo, per icone e favicon |

I file sono una **bozza vettorializzata** (tracciamento automatico delle immagini di riferimento): prima di un uso ufficiale il logo va ridisegnato o verificato da una designer. Colori indicativi: verde scuro `#02402E`/`#003D35`, verde salvia `#B8D9A3`, bianco `#FFFFFF`. Non deformare, ruotare o aggiungere ombre al logo.
